# WärmeMatch Berlin

**WärmeMatch Berlin** is a pilot platform for matching heat supply and demand for local heating networks in Berlin.

> [!IMPORTANT]
> This project is currently in **development** and serves as a **prototype**. It is not yet ready for production use.

## Live Demo
You can test the latest version of the prototype here:
[https://afanegas.github.io/heatmatch/](https://afanegas.github.io/heatmatch/)

## Technologies
- **Frontend:** HTML5, CSS3, and JavaScript
- **Map:** [Leaflet](https://leafletjs.com/) with OpenStreetMap
- **Backend & Database:** [Supabase](https://supabase.com/) (Authentication, PostgreSQL, RLS)
